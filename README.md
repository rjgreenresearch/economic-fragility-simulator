# Economic Fragility Simulator
Companion software for Paper 7: "Compound Economic Fragility"
Robert J. Green | ORCID: 0009-0002-9097-1021

## Quick Start
```
pip install -r requirements.txt
export FRED_API_KEY=your_key_here
python -m econ_fragility.fred_loader --download-all
```

## Six Domains
1. Wage-Productivity Gap
2. Consumer Balance Sheet
3. Fiscal Sustainability
4. Labour Market Transformation
5. Trade Architecture Stress
6. Monetary Policy Constraint
